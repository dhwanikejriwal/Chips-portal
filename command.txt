1. what about this command : .venv\Scripts\alembic revision --autogenerate -m "description of changes"

is only for generating a new instruction file 
when you make changes to your Python files. 
It does not create any tables in your database.


2. When you want to create/update tables in the database: 
Do not run the autogenerate command. Instead, simply start your FastAPI server or run:

.venv\Scripts\alembic upgrade head
