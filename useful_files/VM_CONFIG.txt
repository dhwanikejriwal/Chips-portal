================================================================================
                         TARGET VM SPECIFICATIONS & ENVIRONMENT
================================================================================

[VM HARDWARE & OS CONFIGURATION]
- Operating System:      Rocky Linux (RHEL-compatible enterprise Linux)
- CPU:                   4 Cores (vCPUs)
- Memory (RAM):          8 GB
- Storage - OS Disk:     250 GB (Root filesystem `/`)
- Storage - Data Disk:   250 GB (Dedicated Data/Storage Mount, e.g., `/data` or `/mnt/data`)

--------------------------------------------------------------------------------
[DOCKER ARCHITECTURE & SERVICES (from docker-compose.yml & Dockerfile)]
--------------------------------------------------------------------------------

1. System & Container Base:
   - Base Image: `python:3.12-slim` (Debian-based in container, running on Rocky Linux Docker host)
   - OCR & System Dependencies: `tesseract-ocr`, `tesseract-ocr-hin`, `poppler-utils`, `libpq-dev`, `gcc`, `g++`

2. Services & Port Mapping:
   - `nginx` (chips-nginx):
       * Image: `nginx:alpine`
       * Host Port: `80:80`
       * Config: Reverse proxy to frontend with 50MB max body size & 300s timeouts for OCR.
   - `frontend` (chips-frontend):
       * Server: Gunicorn with `app:create_app()`
       * Command: `gunicorn -w 4 -b 0.0.0.0:5000 --timeout 300`
       * Internal Port: 5000
   - `backend` (chips-backend):
       * Server: Uvicorn with `backend.main:app`
       * Command: `uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 4 --timeout-keep-alive 300`
       * Internal Port: 8000
   - `postgres` (chips-postgres):
       * Image: `postgres:15`
       * Host Port: `127.0.0.1:5432:5432`
       * Database Name: `chips_db_new`

3. Volumes & Storage Layout (Mapped to 250 GB Data Disk):
   - `postgres_data` (External volume: `chips-portal_postgres_data`) -> Mounts `/var/lib/postgresql/data`
   - `uploads_data` (External volume: `chips-portal_uploads_data`) -> Mounts `/app/uploads`
   - Secondary 250 GB Data Disk Setup:
       * Place Docker volume storage or symlinks on the 250GB secondary mount (e.g. `/data/docker-volumes/` or docker data-root `/data/docker`)
       * Pre-create external volumes:
         `docker volume create chips-portal_postgres_data`
         `docker volume create chips-portal_uploads_data`

--------------------------------------------------------------------------------
[RESOURCE & ARCHITECTURE GUIDELINES FOR CODE & DEPLOYMENT]
--------------------------------------------------------------------------------

1. CPU & Worker Concurrency (4 vCPUs):
   - Frontend: 4 Gunicorn workers (handles UI rendering and API proxying)
   - Backend: 4 Uvicorn workers (handles FastAPI endpoints and OCR operations)
   - Concurrency limits / timeouts: 300s timeout configured to allow long-running OCR extraction.

2. Memory Allocation (8 GB RAM):
   - PostgreSQL (chips-postgres): ~1.5 GB - 2 GB
   - Backend (chips-backend + OCR memory spikes): ~2.5 GB - 3 GB
   - Frontend (chips-frontend): ~1 GB - 1.5 GB
   - Nginx + OS + Docker daemon overhead: ~1.5 GB
   - Total fits safely inside 8 GB without risk of OOM kills.

3. Rocky Linux Host Specifics:
   - SELinux: If active, ensure Docker volumes have appropriate SELinux context (`:z` / `:Z` or `setsebool`).
   - Firewall: Open HTTP/HTTPS (`firewall-cmd --permanent --add-service=http --add-service=https && firewall-cmd --reload`).
   - Systemd Service: Enable and start docker (`systemctl enable --now docker`).
